# 使用说明

## 打开图片

| 方式 | 说明 |
| --- | --- |
| 主页「选择图片」或拖放卡 | 文件对话框 / 拖入窗口 |
| 拖到 exe 上 | 命令行 `argv[1]`，启动后直接进编辑器 |
| 编辑器「打开新图…」 | 换图 |
| Ctrl+V、Shift+Insert、Win+V 历史 | 剪贴板图片。格式优先级见 [架构 · 粘贴](architecture.md#粘贴) |

支持 png / jpg / jpeg / bmp / gif / webp / tiff / ico。GIF 取首帧。

## 主页

- 拖放卡：悬停或有文件拖入时蓝框。点卡片或「选择图片」均可打开。
- 设置：默认框选模式、默认翻转方向、外观。改动即时生效并写盘。

## 编辑器

图片按窗口适配（无缩放平移）。选框外压暗；焦点框为强调色描边、中心竖直虚线、角/边手柄。

### 选框

- **移动**：框内拖动
- **缩放**：角手柄双轴，边手柄单轴
- **新框**：非整图模式下，空白处拖拽；过小视为误触，不添加
- **点选**：点某个框获得焦点。重叠时优先当前焦点，否则最上层
- **删框**：多个框时点「删框」，或 Delete / Backspace。至少保留一个

文字模式开启时，空白处点击会加字，不会画新框。

### 人脸框选 / 整图框选 / 加框

- **人脸框选**：按设置里的单人/多人模式检测。单人取面积最大的脸；多人每张脸一个框。检测不到或失败时，在画面中央放一个宽高各 40% 的框，不回退整图。
- **整图框选**：一个铺满全图的框。此时不能加框。
- **加框**：未框住的人脸里取 score 最高者；没有则放中央。整图模式按钮禁用。

打开图片时按「默认框选模式」自动做一次上述逻辑。

### 每框独立设置

选中某个框后：

- **方向**：自动 / 保留左半 / 保留右半。自动按保留侧水平梯度能量，信息量大的一半留下来（打平取左）。
- **查看原图**：该框区域显示原图像素，其它框仍按各自方向镜像。

多个框从原图各自镜像，后写覆盖重叠区。

### 叠加文字

工具栏 **文字** 开关打开第二行字号/颜色条，进入文字模式（光标变成文本）。

- **添加**：点画面空白处，出现输入框。也可点「放到中央」。
- **输入**：支持换行。空内容点别处会丢掉这条。
- **移动**：选中后拖动文字本身，或拖输入框顶上的「拖动移动」。
- **再编辑**：已落下的文字点一下选中（可拖），再点一下进入输入。
- **字号**：16–160，默认约画面短边的 10%。
- **颜色**：白（黑描边）、黑（白描边）、黄（黑描边）。
- **删除**：工具栏「删文字」，或焦点在文字上时按 Delete / Backspace。

文字先画进源图，再按选框镜像，所以落在框里的字会左右对称，效果和照片像素一样。正在输入的那条暂不画进预览，避免和输入框叠两层。

没有微软雅黑 / 黑体 / 宋体时无法绘制，工具栏会提示。

### 输出

- **复制图片**：RGBA 写入剪贴板
- **保存图片**：另存为，默认文件名 `<原名>_qp.png`，按后缀编码

输出尺寸始终等于输入。框外像素不变；选框宽度为奇数时中心列不变。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl+V / Shift+Insert | 粘贴图片 |
| Delete / Backspace | 有焦点文字时删文字；否则删除当前焦点框（多于一个且非整图时） |
