# 使用说明

## 打开图片

| 方式 | 说明 |
| --- | --- |
| 主页「选择图片」或拖放卡 | 文件对话框 / 拖入窗口 |
| 拖到 exe 上 | 命令行 `argv[1]`，启动后直接进编辑器 |
| 编辑器「打开」 | 换图 |
| Ctrl+V、Shift+Insert、Win+V 历史 | 剪贴板图片。格式优先级见 [架构 · 粘贴](architecture.md#粘贴) |

支持 png / jpg / jpeg / bmp / gif / webp / tiff / ico。GIF 取首帧。

## 主页

- 拖放卡：悬停或有文件拖入时蓝框。点卡片或「选择图片」均可打开。
- 设置：默认框选模式、默认镜像方式、默认保留侧、默认仅框选处、外观。改动即时生效并写盘。

## 编辑器

图片按窗口适配（无缩放平移）。选框外压暗；主选框为强调色描边、中心对称轴虚线、角/边手柄。

### 选框

- **移动**：框内拖动
- **缩放**：角手柄双轴，边手柄单轴
- **新框**：非整图模式下，空白处拖拽；过小视为误触，不添加
- **点选**：普通点击单选；Ctrl+点击切换选中状态；Ctrl+A 全选；点击空白或 Esc 清空选择。重叠时优先当前主选框，否则最上层。
- **整体移动**：多个框选中后，拖动任一选中框会整体移动并保持相对位置；主选框仍单独显示缩放手柄。
- **删框**：工具栏 `−` 或 Delete / Backspace 删除全部选中框。工具栏 `+` 加框，旁边的 `已选/总数` 显示选择数量。至少保留一个。

文字模式开启时，空白处点击会加字，不会画新框。

### 人脸框选 / 整图框选 / 加框

- **人脸框选**：按设置里的单人/多人模式出框。单人取面积最大的脸；多人每张脸一个框。同一张图只检测一次，整图框选再切回来直接复用。检测不到或失败时，在画面中央放一个宽高各 40% 的框，不回退整图。
- **整图框选**：一个铺满全图的框。此时不能加框。
- **加框**：未框住的人脸里取 score 最高者；没有则放中央。整图模式按钮禁用。

打开图片时按「默认框选模式」自动做一次上述逻辑。

### 每框独立设置

选中某个框后：

- **镜像方式**：水平翻转或垂直翻转。水平翻转处理左右对称，垂直翻转处理上下对称；默认是水平翻转。
- **保留侧**：水平方式显示自动 / 左半 / 右半；垂直方式显示自动 / 上半 / 下半。自动按当前轴比较两侧梯度能量，信息量大的一侧留下来，打平取第一侧。
- **查看原图**：该框区域显示原图像素，其它框仍按各自设置镜像。
- **显示角标**：每个框独立控制角上编号。全开显示 `✓`，混合显示 `-`，全关为空白；混合状态点击后统一开启。编号关闭时，选中的次级框仍显示独立的强调色勾选标记，不会丢失选择线索。开关和标记带出现/消失动画。

多选时，配置不同的控件不显示选中态。点击一个明确的镜像方式、保留侧或复选框状态后，才将该值批量应用到当前选中框。


多个框从原图各自镜像，后写覆盖重叠区。

### 撤销与重做

- 工具栏左侧 `↶` / `↷` 分别撤销和重做；按钮禁用时表示没有对应历史。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。历史最多保留 100 步；打开新图片会重新开始。
- 选框移动、缩放、新增、删除、属性批量应用，以及一次完整的选择/焦点变化各记为一步。拖动过程中按 Ctrl+Z 会先取消当前未提交拖动，再撤销上一笔。
- 选择变化也进入历史；撤销选择只更新选框和工具栏，不重新合成图片。

### 叠加文字

工具栏 **文字** 开关（选中有过渡动画）展开第二行字号/颜色条，进入文字模式（光标变成文本）。

- **添加**：点画面空白处，出现输入框。也可点「放到中央」。
- **输入**：支持换行。空内容点别处会丢掉这条。
- **移动**：选中后拖动文字本身，或拖输入框里的「拖动移动」。
- **再编辑**：已落下的文字点一下选中（可拖），再点一下进入输入。
- **字号**：16–160，默认约画面短边的 10%。
- **颜色**：白 / 黄 / 红（黑描边）、黑（白描边）。
- **删除**：工具栏「删文字」，或焦点在文字上时按 Delete / Backspace。

文字先画进源图，再按选框镜像，所以落在框里的字会随当前水平或垂直方式对称，效果和照片像素一样。正在输入的那条暂不画进预览，避免和输入框叠两层。

没有微软雅黑 / 黑体 / 宋体时无法绘制，工具栏会提示。

### 输出

- **仅框选处**：工具栏右侧始终显示。单框时可切换，勾上后复制和保存只保留框内画面；多框时控件与文字灰显、开关状态保持不变，输出整图。状态变化使用 WinUI 过渡动画。初始勾选跟主页「默认仅保留框选处」走。
- **复制图片**：RGBA 写入剪贴板
- **保存图片**：另存为，默认文件名 `<原名>_qp.png`，按后缀编码

未勾选「仅框选处」时输出尺寸等于输入。框外像素不变；水平翻转时奇数宽中心列不变，垂直翻转时奇数高中心行不变。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl+V / Shift+Insert | 粘贴图片 |
| Ctrl+点击 | 加入或移出当前框选择 |
| Ctrl+A | 选择全部框（文字输入框聚焦时由文字编辑器处理） |
| Esc | 清空框选择 |
| Delete / Backspace | 有焦点文字时删文字；否则删除全部选中框（至少保留一个） |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
